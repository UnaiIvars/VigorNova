COMO ACTIVAR VIGORNOVA EN ESTE ORDENADOR
--------------------------------------

Si acabas de descargar este proyecto o te lo han pasado en una carpeta, sigue estos pasos para poder verlo funcionar:

1. INSTALAR EL MOTOR (Node.js)
   ---------------------------
   Para que esta web funcione, necesitas tener instalado Node.js. 
   Puedes descargarlo gratis en: https://nodejs.org/ (recomiendo la versión LTS).

2. INSTALAR LAS PIEZAS (Dependencias)
   ---------------------------------
   Abre una terminal/consola dentro de esta carpeta y escribe el siguiente comando:
   
   npm install

   (Esto descargará todas las librerías necesarias. Solo hay que hacerlo la primera vez).

3. CONFIGURAR LAS LLAVES (Base de datos)
   -------------------------------------
   Asegúrate de que existe un archivo llamado ".env.local" en esta carpeta con tus claves de Supabase. 
   Si no lo tienes, la web no podrá conectar con la base de datos ni permitir el login de usuarios.

4. ¡A VOLAR!
   ----------
   Ahora ya puedes hacer doble clic en el archivo "VER_WEB.bat" para encender la web y verla en tu navegador.
